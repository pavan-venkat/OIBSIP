# Task1: Reservation System
### Objective
To build a console-based reservation system for train booking that allows users to book, cancel, and view reservations.
### Tech Stack
- Java, OOPs, Collections (ArrayList), Scanner Class
### Features Checklist
- [x] User Login
- [x] Book Ticket (Name, Train No, Class, Date)
- [x] Cancel Ticket using PNR
- [x] View All Bookings
### How to Run
javac ReservationSystem.java
java ReservationSystem
